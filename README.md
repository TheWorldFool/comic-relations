# 页间 · Comic Relations

**按页读漫画，按转折看关系。**

[English](README.en.md) · [详细使用说明](docs/GUIDE.zh-CN.md) · [反馈问题](https://github.com/TheWorldFool/comic-relations/issues)

页间是一个本地运行的漫画关系阅读工作台。导入并排序漫画图片后，通过 DeepSeek API 逐页分析剧情、辨认人物、整理角色档案，并在重要剧情转折处保存人物关系图。每个阶段和关系证据都保留漫画页码，方便在原稿与分析结果之间核对。

**当前状态：v0.1 早期版本。** 核心流程已实现，适合个人试用、开发与反馈；人物身份、关系与阶段划分仍需人工核对，尚未进行跨作品的系统性准确率评估。界面和默认分析输出以中文为主。

## 能做什么

| 功能 | 行为 |
| --- | --- |
| 导入与整理 | 导入图片或文件夹，自然排序、拖动调整页序，设置分格阅读方向。 |
| 先划分再分析 | 用户在阅读前批量标注正文、封面、广告、附页；非正文不进入剧情分析。 |
| 背景检索 | 从漫画中识别原作线索，联网检索背景与角色参考；展示来源，用户采用后才加入分析上下文。 |
| 人物身份维护 | 独立保存逐页出场与归属证据，支持按次校正并重算当前关系和状态；按需复核，存疑裁图不自动进入人物参考库。支持已有档案复核、人工合并与回退。 |
| 阶段关系图 | 日常互动更新当前阶段，重要且持续的关系或状态转折才新增阶段，不逐页生成一张新图。 |
| 角色档案 | 整理身份、外观、状态、对其他人的态度与证据页码；不强制套用固定属性或好感分数。 |
| 关系工作台 | 画布拖动、缩放、整理布局、展开详情、独立标签页查看；支持人物档案搜索。 |
| 保存与恢复 | 每页完成后保存，失败时保留进度，继续分析从未完成页开始；支持导出分析 JSON。 |

没有预置漫画、演示人物或伪造的剧情数据。背景资料仅辅助辨认，原作设定不能直接当作当前漫画已经发生的情节。

## 快速开始

需要 **Node.js 22.12+**、npm，以及支持图片输入和 JSON 输出的模型 API。本项目在 Node.js 24 / Windows 上进行过本地验证。

```bash
git clone https://github.com/TheWorldFool/comic-relations.git
cd comic-relations
npm ci
npm run build
npm start
```

打开 **http://127.0.0.1:3001**，在“阅读设置”中填写 API 地址、模型名称和 API Key，再测试图片连接。Windows PowerShell 如拦截 `npm.ps1`，可将上述命令中的 `npm` 换为 `npm.cmd`。

也可复制 `.env.example` 为 `.env` 后填写配置：

```dotenv
DEEPSEEK_API_KEY=your_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

默认集成 DeepSeek。自定义服务必须支持应用使用的图片输入与 JSON 请求格式；自动背景检索还需要兼容 DeepSeek Anthropic Web Search，不能把普通聊天接口当作联网搜索接口。模型可用性以服务商为准。[DeepSeek 搜索能力说明](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/#using-web-search-in-claude-code)

## 使用流程

1. **导入并排序**：支持 JPG、PNG、WebP 和 GIF 静态首帧；单张最大 32 MB，单次最多 1000 张。
2. **确认页面用途**：批量标记正文、封面、广告或附页。所有页面确认后才能开始阅读。
3. **核对背景**：可自动查找原作背景，查看来源后采用，也可不使用背景检索直接分析。
4. **开始分析**：顺序读取正文，提取人物、事件、状态和关系；失败时查看错误并从断点继续。
5. **查看关系**：切换“阅读对照”或“关系工作台”，点击“独立打开关系图”可在另一标签页查看。选阶段看历史，点人物看档案，点关系看证据，点页码返回原稿。
6. **校正与导出**：人工归并重复人物、重新裁剪头像，或导出项目分析 JSON。

修改已读页面的顺序、用途、分格方向或删除页面，需要清除受其影响的分析并重新阅读；界面会先提示。源漫画文件不会被修改。

## 本地数据与 API 用量

- 项目、图片、头像与分析结果存放在 `data/`；`data/` 和 `.env` 均不纳入 Git。
- “本地运行”不等于离线分析：正文图片、必要的参考头像/前页图片及剧情上下文会发送到你配置的 API。背景识别也会发送所选样本页。
- 连接测试、漫画分析、自动修正与背景检索可能产生 API 费用；没有固定的每页费用保证。
- UI 保存的 API Key 位于本机 `data/settings.json`，不是加密密钥库。不要分享整个数据目录。
- 失败诊断可能包含模型生成的漫画文本。反馈问题时请脱敏，不要附带密钥或未经授权的漫画内容。
- 服务只监听 `127.0.0.1`，没有多用户认证；本版本面向个人本机使用。

## 当前边界

- 模型可能误认角色、遗漏关系或错误划分阶段；来源链接匹配也不等于背景事实已经完全核实。
- 未完成覆盖多种画风、语言和长篇作品的质量评估，也尚未完成完整的浏览器视觉与交互验收。
- 第三方模型可能拒绝某些内容；应用保留内容拒绝状态，不通过格式修正绕过限制。
- 暂不支持 PDF / ZIP / CBZ 导入、独立 OCR 校对、多人协作与公网托管。
- 头像裁剪依赖模型坐标，提供人工框选作为修正入口。

## 开发与提示词

```bash
npm run dev    # 前端 http://127.0.0.1:5173，后端 3001
npm test       # 隔离临时目录及模拟 API，不需要真实密钥
npm run build # TypeScript 检查与前端构建
```

`npm run test:live` 是可选的付费接口测试，使用单独生成的简单测试图，不会读取用户书架。

技术栈：React、TypeScript、Vite、Express、React Flow、Dagre、Sharp、Zod。

| 位置 | 用途 |
| --- | --- |
| `server/analysis.ts` | `systemPrompt` 主提示词、阅读结构、关系阶段更新 |
| `server/provider.ts` | 模型请求、输出校验与自动修正 |
| `server/reading-memory.ts` / `server/reading-images.ts` | 增量剧情记忆、定期汇总与图片预取缓存 |
| `server/background-research.ts` | 原作识别、联网背景检索与来源校验提示词 |
| `server/identity.ts` | 人物身份匹配、归并与引用重写 |
| `src/RelationshipExplorer.tsx` | 阶段导航、关系图与详情查看 |
| `src/CharacterDossier.tsx` | 人物档案、状态与证据 |
| `tests/` | 数据逻辑、组件输出与 HTTP 集成回归测试 |

修改后端提示词后需重启服务；已有分析不会自动重算。更详细的规则、配置和恢复行为见[使用与实现说明](docs/GUIDE.zh-CN.md)。
